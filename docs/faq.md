# FAQ

**What counts as used?**
At least two matching access lines inside the window. A single line is treated
as insufficient evidence and the verdict stays unused.

**Why is an empty log not unused?**
No data is not the same as no use. The verdict is unknown so the review sees
the difference.

**Does it connect to the IdP?**
No. It reads exported files, which is why a review can be reproduced from the
same inputs later.
